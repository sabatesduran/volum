Useful answers

Before you point Volum at a folder.

Is Volum really free and open source?

Yes. There is no trial, subscription, account, or model limit. Volum is licensed under GPL-3.0-or-later, and its source code and releases are public on GitHub.

Does Volum move or rename my files?

No. Volum indexes files in place. Collections, tags, favorites, notes, costs, and saved searches live in its local database without changing your folder structure.

Which formats are supported?

STL, OBJ, 3MF, and STEP/STP projects have generated previews and interactive geometry. STEP/STP support uses OpenCascade for metadata, tessellation, thumbnails, and geometry analysis.

Can duplicate cleanup delete the wrong file?

Volum never cleans up automatically. It separates exact files from geometry matches, recommends a keeper, preserves companion files and organization metadata, and uses the operating system Trash when you approve cleanup.

Does the desktop app need an internet connection?

No connection is required to browse your library. Network access is only used for optional update checks, backups you configure, and public MakerWorld or Printables metadata when you preview a link.

What if files move or a library drive is disconnected?

Volum uses stable file fingerprints to recognize moved files and keeps metadata while removable or mounted libraries are unavailable. You can reconnect an offline library at a new path without rebuilding your organization.

What does a Volum backup contain?

A portable, checksummed ZIP containing Volum’s organization, settings, attribution, and user-owned media. It never includes or replaces original STL, 3MF, OBJ, STEP, or STP files. Archives are validated before restore, and Volum first makes a safety backup of its current data.

Does web import download protected files?

No. Volum reads public MakerWorld or Printables metadata and lets you attach files you downloaded through the official provider. It never asks for provider credentials.
