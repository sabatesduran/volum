A few useful answers

Before you make room for Volum.

Does Volum move or rename my files?+

No. Volum indexes files in place. Collections, tags, favorites, notes, and estimates live in its local database without changing your folder structure.

Which formats are supported?+

STL, OBJ, 3MF, STEP/STP, and ZIP files are indexed. STL, OBJ, and 3MF have interactive geometry previews; STEP/STP tessellation is intentionally marked as pending.

Does web import download protected files?+

No. Volum reads public MakerWorld or Printables metadata and lets you attach files you downloaded through the official provider. It never asks for provider credentials.

Is Volum free and open source?+

Yes. Volum is licensed under GPL-3.0-or-later. Source code and releases are available on GitHub. If Volum is useful to you, please star the project—it helps more makers discover it.
