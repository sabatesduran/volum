# Code of conduct

Volum follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate. Harassment, discrimination, personal attacks, and publishing another person’s private information are not acceptable. Maintainers may remove content or participation that violates these expectations.

Report conduct issues privately to the project maintainers through the canonical repository.
